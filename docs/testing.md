# Pruebas de Software - TaskFlow Pro

## Pruebas Manuales
- **Creación:** Se validó que las tareas se guardan en el servidor Express.
- **Persistencia:** Al reiniciar el servidor, los datos se mantienen en memoria (o se resetean según diseño).
- **Validación:** El formulario no permite tareas vacías.
