# Gestión del Proyecto - TaskFlow

## Metodología de Organización

Para el desarrollo de TaskFlow, utilicé **Trello** como herramienta principal de gestión de proyectos, aplicando principios de **Kanban** para organizar el flujo de trabajo de manera visual y eficiente.

## Estructura del Tablero Trello

El tablero se organizó con las siguientes columnas:

### 📋 **Backlog**
- Todas las funcionalidades requeridas por la Fase 5
- Ideas y mejoras futuras
- Bugs reportados

### 📝 **Todo (Por Hacer)**
- Tareas seleccionadas para el sprint actual
- Priorizadas por importancia
- Estimación de tiempo incluida

### ⚡ **In Progress (En Progreso)**
- Máximo 3-4 tareas simultáneas
- Indicador de quién trabaja en cada una
- Fecha límite visible

### 👀 **Review (Revisión)**
- Código completado, pendiente de testing
- Verificación de funcionalidad
- Revisión de estilo y UX

### ✅ **Done (Completado)**
- Funcionalidades terminadas y probadas
- Documentación actualizada
- Deploy exitoso en Vercel

## Flujo de Trabajo

1. **Planificación**: Cada semana seleccionaba tareas del Backlog y las movía a Todo
2. **Ejecución**: Movía las tareas a In Progress conforme comenzaba a trabajar
3. **Testing**: Al completar el código, pasaba a Review para pruebas manuales
4. **Completado**: Tras verificar que todo funcionaba, movía a Done

## Ventajas de Kanban para este Proyecto

- ✅ Visualización clara del progreso
- ✅ Limitación del trabajo en progreso (WIP)
- ✅ Flexibilidad para priorizar tareas
- ✅ Identificación rápida de cuellos de botella
- ✅ Adaptabilidad a cambios de requisitos
