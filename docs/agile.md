# Investigación: Metodologías de Desarrollo

## 1. ¿Qué es Agile?
Es una filosofía orientada al desarrollo de software que prioriza la **entrega continua de valor**, la capacidad de respuesta ante los cambios y la colaboración constante entre el equipo y el cliente. A diferencia de los modelos tradicionales, Agile divide el proyecto en partes pequeñas para entregarlas de forma incremental.

## 2. Scrum
Es un marco de trabajo (framework) que organiza el desarrollo en ciclos cerrados.
* **Roles clave:** * *Product Owner:* Define las prioridades del negocio.
    * *Scrum Master:* Elimina obstáculos y asegura que el equipo siga el proceso.
    * *Equipo de Desarrollo:* Ejecuta el trabajo técnico.
* **Conceptos:**
    * *Sprint:* Ciclo de trabajo de tiempo fijo (normalmente 2 semanas).
    * *Backlog:* Lista maestra de tareas pendientes.
    * *Sprint Review:* Reunión para mostrar el software funcional al finalizar el ciclo.

## 3. Kanban
Es un método visual para gestionar el flujo de trabajo. Se basa en un tablero con columnas que representan los estados de una tarea.
* **Tablero Kanban:** Visualización del flujo desde "Por hacer" hasta "Hecho".
* **Límite WIP (Work In Progress):** Estrategia para limitar el número de tareas activas y evitar cuellos de botella.

## 4. Diferencias y Casos de Uso
| Característica | Scrum | Kanban |
| :--- | :--- | :--- |
| **Tiempo** | Ciclos fijos (Sprints) | Flujo continuo |
| **Roles** | Roles definidos obligatorios | No requiere roles específicos |
| **Cambios** | No se añaden tareas durante el Sprint | Permite añadir tareas en cualquier momento |

* **Cuándo usar Scrum:** En proyectos nuevos con objetivos complejos que requieren una estructura rítmica.
* **Cuándo usar Kanban:** En mantenimiento o soporte técnico donde el trabajo es constante y las prioridades cambian día a día.
