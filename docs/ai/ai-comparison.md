# Comparativa de Modelos de IA

Este documento está destinado a registrar y comparar las capacidades de las distintas IAs utilizadas en este proyecto (**ChatGPT** y **Claude**). El objetivo es identificar qué modelo resuelve mejor cada tipo de tarea técnica.

## Tabla Comparativa Inicial

| Característica | ChatGPT (OpenAI) | Claude (Anthropic) |
| :--- | :--- | :--- |
| **Punto Fuerte** | Versatilidad y rapidez | Razonamiento lógico y redacción |
| **Código** | Ideal para boilerplates | Excelente para refactorización |
| **Contexto** | Gran capacidad de búsqueda | Análisis profundo de archivos largos |
