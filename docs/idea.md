# Definición del Proyecto: Task Flow

## Problema que resuelve
**Task Flow** surge para solucionar el caos en la organización de tareas diarias. Muchos usuarios se sienten abrumados por herramientas demasiado complejas o demasiado simples. Esta aplicación ofrece un equilibrio profesional, permitiendo gestionar flujos de trabajo con una interfaz intuitiva basada en React y una persistencia de datos robusta en el backend.

## Usuario objetivo
* **Freelancers** que necesitan organizar sus proyectos.
* **Estudiantes de programación** que buscan una herramienta con estética técnica.
* **Equipos pequeños** que prefieren simplicidad y velocidad.

## Funcionalidades principales
1. **Gestión CRUD:** Crear, leer, actualizar y eliminar tareas.
2. **Arquitectura Fullstack:** Conexión real con una API en Node.js.
3. **Interfaz Dinámica:** Estados visuales de carga (loading) y gestión de errores.
4. **Categorización:** Clasificación de tareas mediante etiquetas.

## Funcionalidades opcionales
* Filtros de búsqueda por prioridad o fecha.
* Implementación de **Modo Oscuro** persistente.
* Notificaciones visuales al completar objetivos.

## Mejoras futuras
* Sistema de **Autenticación de Usuarios**.
* Soporte para **Drag & Drop** en el orden de las tareas.
* Generación de reportes de productividad en PDF.
