# Registro de Prompt Engineering

### Prompt 1: Conceptos Técnicos
> "Explica de forma clara y con código: Closures, Event Loop y Hoisting en JS."

### Prompt 2: Debugging
> "Encuentra los errores en estas funciones: [se pegaron las funciones con fallos]"

### Prompt 3: Creación de funciones
> "Crea tres funciones en JS: una de números primos, otra de CamelCase y otra de cálculo de IVA al 21%."

**Lección aprendida:** Cuanto más específico soy con las restricciones (ej: "usa constantes para el IVA"), mejor es el código que entregan.
