# Registro de Prompt Engineering

Este documento es el diario de instrucciones del proyecto. Aquí se guardarán los prompts que mejores resultados hayan dado para poder reutilizarlos.

## Estructura de Registro
* **Prompt:** La instrucción enviada.
* **Modelo:** (ChatGPT / Claude).
* **Resultado:** Si fue exitoso o necesitó ajustes.
* **Lección:** Qué palabra clave o contexto cambió el resultado.

---
*El primer prompt registrado será la base de la arquitectura del proyecto.*
